
# FinStudy — 財金學習筆記網站

FinStudy 是一個使用 HTML、CSS 和 JavaScript 製作的財金學習筆記網站。

網站整理財務管理、風險管理等課程內容，透過核心概念、重要公式、例題及考試重點，協助學生複習。

## 網站功能

- 首頁筆記卡片
- 科目分類
- 筆記詳細內容
- 返回首頁導覽
- 響應式網頁設計

目前以分類功能為主，文字搜尋功能可作為未來擴充項目。

## AI 協作規範

本專案透過 AGENTS.md 指導 AI 如何持續擴充網站。

AGENTS.md 規定：

- 專案目標
- 技術與視覺規範
- 檔案結構
- 命名規則
- 筆記內容格式
- 新增主題的八步驟 SOP
- 修改限制
- 測試與完成標準

## 新增筆記流程

1. 確認主題與科目。
2. 整理原始資料。
3. 建立知識架構。
4. 製作 Markdown 筆記。
5. 製作 HTML 網頁。
6. 更新首頁卡片。
7. 測試連結與內容。
8. 回報修改結果。

## AI 擴充範例

例如要求 AI：

「請閱讀 AGENTS.md，新增『年金現值』筆記。」

AI 應按照規範建立 Markdown 與 HTML，沿用既有網站風格，更新首頁索引，並檢查連結及公式。

「現值與終值」可作為網站目前的筆記格式參考。
